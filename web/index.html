Bazzite setup

This AppImage bundles the bridge and dashboard. It needs no Python, extra packages, or Windows drivers. The dashboard runs only on your own computer.

1. Device permissions, only if needed

If your rig is missing or starting output reports permission denied, choose its USB entry below. The command installs a device-specific access rule and enables Linux's existing virtual-input module. It modifies two small files under /etc; it does not install packages or change the operating-system image.

Select your controller, not a keyboard, mouse, or USB hub. If its name is unclear, unplug/replug it and reopen the app to compare the list.

Choose the controller to generate its setup command.

Run the command once in a terminal, then unplug/replug the rig. Launch the app normally afterward. Do not run the dashboard with sudo. If access remains denied, log out and back in or reboot.

2. Calibrate and start

  1. Use the joystick firmware with joystickMode = true.
  2. Connect the rig in this dashboard. Capture both stops for each handle, then apply and save.
  3. Start output. Move both handles to idle and release all buttons and toggles to arm it.
  4. Open Steam's controller test and check Podracer Bridge Xbox 360. Then launch the game with its default controller scheme.

3. While playing

Keep the app running. Closing the browser tab does not stop the bridge. Reopen the dashboard using its launch URL, or stop the app from its terminal. Use Stop output before changing games; Quit app releases inputs and closes the engine.

The physical joystick is reserved while output is active to reduce duplicate input. If Steam still sees both devices, select the virtual gamepad and avoid binding the physical Arduino. Steam Input settings vary by game; test the virtual controller before adjusting those settings. No rumble is provided.

Recovery

Unplugging the rig stops virtual output. Reconnect it explicitly; output never restarts automatically. Changing settings or loading a profile also stops output. After sleep/suspend, start output again. The bridge does not detect whether your game is focused.

Removing the permission setup

Delete only the 70-podracer-bridge-VENDOR-PRODUCT.rules file created for your rig from /etc/udev/rules.d, and /etc/modules-load.d/podracer-bridge.conf if you no longer use the bridge. Reboot to apply. Profiles remain in your home folder.
